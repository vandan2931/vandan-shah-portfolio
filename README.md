## 🛠 Development Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/vandan2931/vandan-shah-portfolio.git
   cd vandan-shah-portfolio
   ```

2. Open in browser:
   ```bash
   # For Linux/macOS:
   open index.html

   # For Windows:
   start index.html
   ```

3. For development:
   - Live Server extension in VS Code recommended
   - Chrome DevTools for debugging

## 🌐 Deployment Options

### GitHub Pages
1. Go to Repository Settings
2. Navigate to Pages section
3. Select `main` branch and root folder
4. Save to deploy (live in 1-2 minutes)

### Netlify
1. Drag and drop project folder
2. Automatic CI/CD from GitHub

### Vercel
1. Import Git repository
2. Zero-config deployment
